Descargar ExtractX v1.2.1

Elige: instalador con menú de clic derecho, o portable de un solo archivo.

Instalador Recomendado

Asocia formatos, añade Extraer / Comprimir con ExtractX al clic derecho, crea accesos directos y trae el motor 7-Zip. Desinstalador propio incluido.

Descargar Setup Si el enlace falla: el Setup está en la carpeta dist/ junto al payload.

Instalación silenciosa

ExtractX-Setup.exe --silent --dir="C:\ExtractX" --formats=zip,rar,7z
Uninstall.exe --uninstall --silent

Portable

Un solo .exe autocontenido, sin instalación. Doble clic y a extraer. Desde Configuración también asocia formatos en modo usuario.

Descargar Portable (~129 MB) Requiere .NET 9 Desktop Runtime solo para el instalador ligero; el portable no pide nada.

Requisitos

  • Windows 10 / 11 de 64 bits
  • El instalador instala solo .NET 9 si falta (con tu permiso)
  • Crear RAR necesita WinRAR instalado (formato propietario de RARLAB)
  • Tus datos viven en %AppData%\ExtractX: nada sale de tu equipo
